# AI Strategy Bolted On vs Built In

This example demonstrates the difference between 'bolting on' AI capabilities and 'building in' AI as a core part of a system. It presents two simple task managers: one where an AI suggestion feature is an external add-on, and another where AI-driven task prioritization is integral to the system's core logic. The 'built-in' example highlights how disabling AI directly impacts fundamental operations like task addition and listing.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
